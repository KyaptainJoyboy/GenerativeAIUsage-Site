# Generative AI Misuse Website

A simple HTML/CSS/JavaScript recreation inspired by the uploaded Canva design.

## Files

- index.html — website structure/content
- style.css — colors, layout, responsive design, animations
- script.js — navbar, active section, scroll reveal, and mini quiz
- images/ — put your own Canva-exported images here

## Adding your images

Place your images in the `images` folder and use these filenames:

- ai-usage.jpg
- ai-danger.jpg
- fingers.jpg
- ai-art.jpg
- ai-robot.jpg

If your files have different names, simply change the `src="images/..."` value in `index.html`.

## Run it

You do NOT need a server.

Just double-click `index.html` and open it in your browser.

For the best development experience, use VS Code + Live Server.
